Gerar códigos de acesso

Gere os códigos depois de cada venda, envie ao cliente e cole o bloco gerado em assets/js/licencas.js. Só o hash entra no site — o código completa continua só com você e o cliente.

1. Configurar o lote

Cada código libera o plano escolhido até a data de validade.

2. Códigos deste lote

Envie um código por cliente (e-mail, WhatsApp ou junto ao produto). Cada código serve em qualquer navegador, uma vez por licença.

3. Cole este bloco em assets/js/licencas.js

Adicione as linhas dentro do array window.EBOOKS_LICENCAS e publique. Sem esse passo o código não é reconhecido.

Limites do modelo sem servidor: um código não pode ser forjado (o site só conhece o hash), mas pode ser compartilhado por quem o recebeu. Para bloquear por dispositivo ou por assinatura recorrente, é preciso um backend — o próximo passo natural é validar o código em uma função do Vercel com banco de dados.
